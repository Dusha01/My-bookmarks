# 🐧 My-bookmarks

Заметки и шпаргалки по **администрированию Linux**: настройки, утилиты, повседневные рецепты.

Репозиторий публичный — можно копировать конфиги, адаптировать под себя и дополнять своими идеями.

---

## 📚 О проекте

Здесь собираются короткие практические гайды:

- первоначальная настройка окружения
- конфиги shell / редакторов / git
- полезные команды и утилиты
- заметки «как я это делаю на своей машине»

Без тяжёлой теории — только то, что реально пригождается после установки ОС.

## 🚀 Быстрый старт

1. Открой нужную заметку из таблицы выше.
2. Скопируй блоки конфигов в свои файлы (`~/.nanorc`, `~/.bashrc`, `~/.gitconfig` и т.д.).
3. Примени изменения:

```bash
source ~/.bashrc
```
